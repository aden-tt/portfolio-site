UE5 Plugin for Project Setup

Background

Context

The studio is developing a multiplayer party game featuring a large, continuously expanding collection of modular minigames. These minigames are built in Unreal Engine 5 (UE5) and rely on a highly complex, proprietary gameplay framework to function within the larger game ecosystem.

Problem

As production scaled, setting up new UE5 environments for individual minigames became a major bottleneck. Manually configuring each new project to align with our complex internal framework was time-consuming and prone to human error. Furthermore, we needed a way to empower non-technical designers and external third-party developers to build minigames without requiring them to navigate a steep technical learning curve or deal with backend setup hassles.

Task

Design and engineer an automated project-generation tool to streamline the setup of new minigame environments.
